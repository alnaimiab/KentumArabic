# دليل تثبيت تعريب Kentum

## التثبيت في ٣ خطوات

### ١. افتح مجلد اللعبة
في Steam: اضغط بزر الفأرة الأيمن على **Kentum** ← **Manage** ← **Browse local files**.

المجلد الصحيح هو الذي يحتوي على ملف `Kentum.exe`، وغالبًا يكون:
```
C:\Program Files (x86)\Steam\steamapps\common\Kentum
```

### ٢. فك ضغط ملف التعريب هنا
نزّل `KentumArabic-Full-vX.Y.Z.zip` وفك ضغطه **داخل هذا المجلد مباشرة**.

بعد الفك يجب أن ترى هذه الملفات بجانب `Kentum.exe`:
```
Kentum.exe
winhttp.dll            ← جديد
doorstop_config.ini    ← جديد
BepInEx\               ← جديد
Kentum_Data\
```

> إذا وجدت مجلدًا اسمه `KentumArabic-Full-vX.Y.Z` بداخله هذه الملفات، فقد فككت الضغط بمستوى زائد. انقل محتوياته مستوى واحدًا للأعلى.

### ٣. شغّل اللعبة واختر العربية
**Options** ← **Language** ← **العربية**

انتهى. لا حاجة لأي خطوة أخرى.

## حل المشكلات

### اللغة العربية لا تظهر في القائمة
غالبًا لم يُحمَّل التعريب أصلًا. افتح:
```
<مجلد اللعبة>\BepInEx\LogOutput.log
```
ابحث عن السطر:
```
Arabic registered as language id 10
```
- **إذا لم يوجد الملف أصلًا** → `winhttp.dll` ليس في المكان الصحيح. تأكد أنه بجانب `Kentum.exe` مباشرة لا داخل مجلد فرعي.
- **إذا وُجد الملف بلا هذا السطر** → ابحث فيه عن أسطر `[Error` وأرفقها عند الإبلاغ عن المشكلة.

### النص يظهر مربعات فارغة □□□
ملف الخط مفقود. تأكد من وجود:
```
BepInEx\plugins\KentumArabic\fonts\NotoNaskhArabic-Regular.ttf
```

### الحروف غير متصلة أو النص معكوس
افتح `BepInEx\config\com.kentum.arabic.cfg` وتأكد أن:
```
Mode = RtlLayout
```

### بعض النصوص ما زالت بالإنجليزية
هذا متوقع — الترجمة لم تكتمل بعد. النصوص غير المترجمة تظهر بالإنجليزية بشكل طبيعي ولا تسبب أي خلل. تابع [صفحة الإصدارات](../../releases) للتحديثات.

### Windows يعرض تحذير أمان
يستخدم التعريب أداة **BepInEx** المفتوحة المصدر، وهي تعمل عبر ملف `winhttp.dll`، وهذا النمط يثير تحذير SmartScreen أحيانًا. بصمات التحقق (SHA-256) لكل ملف منشورة مع كل إصدار للمقارنة.

### هل يؤثر على الإنجازات أو اللعب الجماعي؟
لا. التعريب يغيّر النصوص المعروضة فقط، ولا يمسّ حالة اللعب ولا الشبكة، ولا يستخدم أوامر الغش في اللعبة (وهي وحدها ما يعطّل الإنجازات).

### تحديث اللعبة على Steam أوقف التعريب
غالبًا سيستمر التعريب في العمل، مع ظهور النصوص الجديدة بالإنجليزية. إن حدث خلل، نزّل أحدث إصدار من التعريب.

## تحديث الترجمة فقط
نزّل `KentumArabic-Content-*.zip` واستبدل به:
```
BepInEx\plugins\KentumArabic\strings\
```
لا حاجة لإعادة تثبيت أي شيء آخر.

## متى يظهر التغيير؟

نسخ الملفات وحده لا يكفي دائمًا — اللعبة تقرأ كل نوع في وقت مختلف:

| ما تغيّر | متى يظهر |
|---|---|
| ملفات الترجمة `strings\` | **فورًا** بمفتاح `Ctrl+Alt+R` داخل اللعبة، أو عند التشغيل التالي |
| الخط، أو `KentumArabic.dll` | **بعد إغلاق اللعبة وتشغيلها من جديد** — الخط يُبنى مرة واحدة عند الإقلاع |
| ملف الإعدادات `com.kentum.arabic.cfg` | عند التشغيل التالي |

**نقطة يسهل أن تخدعك:** يكتب BepInEx كل القيم الافتراضية في ملف الإعدادات عند أول تشغيل، وبعدها **القيمة المحفوظة تغلب الافتراضي الجديد**. فلو غيّرنا الخط الافتراضي في إصدار لاحق، لن يصل التغيير إلى من ثبّت قبله. تعالج الإضافة ذلك تلقائيًا: إن كانت قيمتك ما زالت مساوية للافتراضي القديم — أي أنك لم تخترها — تُنقل إلى الجديد، وإن كنت اخترت خطًا بنفسك فلا يُمَس اختيارك.

يمكنك دائمًا تجاوز ذلك يدويًا: افتح الملف وغيّر سطر `FontFile`، أو اضغط `Ctrl+Alt+N` أثناء اللعب لتجريب الخطوط المرفقة واحدًا تلو الآخر.

## إلغاء التثبيت
احذف من مجلد اللعبة:
```
winhttp.dll
doorstop_config.ini
.doorstop_version
changelog.txt
BepInEx\
```
تعود اللعبة لحالتها الأصلية تمامًا. (ويمكنك أيضًا استخدام **Verify integrity of game files** في Steam.)
